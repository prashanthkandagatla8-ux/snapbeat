2. CONTABO VPS vs. MODAL SERVERLESS - HEAD-TO-HEAD COMPARISON
--------------------------------------------------------------------------------

+----------------------+-----------------------------+-----------------------------+
| Feature              | Contabo VPS (Cloud VPS M)   | Modal Serverless (modal.com)|
+----------------------+-----------------------------+-----------------------------+
| Architecture Model   | Dedicated 24/7 Linux Server | Pay-per-Second Container    |
| Monthly Cost Model   | Fixed Flat Rate ($15/month) | Usage-Based ($0 when idle)  |

| Datacenter Region    | Mumbai, India (Local IP)    | US / Europe cloud regions   |

| Traffic Surge Risk   | High (Queue bottlenecks)    | Zero (Instantly spins up)   |
| Server Management    | You maintain Ubuntu/systemd | Zero Ops (Pure Python code) |
+----------------------+-----------------------------+-----------------------------+

A. Contabo VPS (Cloud VPS M)
   * Price: ~$14 - $18 / month (~₹1,200 - ₹1,500 / month)
   * Specs: 6 vCPU Cores, 16 GB RAM, 400 GB SSD (or 100 GB NVMe)
   * Location: Mumbai, India datacenter available.
   * Strengths:
     - 6 dedicated CPU cores and 16 GB RAM for a tiny fraction of GCP.
     - Files stay inside India -> fastest upload of photos & download of reels.
     - Uncapped rendering: 1,000 renders/day still costs the exact same $15.
   * Weaknesses:
     - Fixed compute ceiling. If 10 users click render simultaneously, jobs
       must queue up and wait.

B. Modal Serverless (modal.com)
   * Price: ~$0.10 / CPU-core hour (~$0.00045 per 15-second 4-core render)
   * Free Allowance: $30 of free compute every month for every account.
   * Strengths:
     - Completely free at low volume (first ~60,000 render-seconds are $0).
     - Scale-to-Zero: At night when no one is rendering, your cost is $0.00.
     - Massive concurrency: If an Instagram/TikTok trend explodes and 100 users
       hit render at once, Modal spawns 100 isolated workers in under 2 seconds.
   * Weaknesses:
     - Datacenters are currently in US/EU. Uploading 15 MB of photos across the
       ocean adds ~1.5 to 2.5 seconds of network transit time for Indian users.

5. RECOMMENDED PRODUCTION STRATEGY: THE HYBRID ARCHITECTURE
--------------------------------------------------------------------------------
The optimal setup that blends low latency, rock-bottom cost, and unlimited burst:

1. Primary Gateway & Free Queue -> Contabo VPS (Mumbai) @ ~$15/month:
   - Hosts api.snapbeat.app (Nginx / SSL / FastAPI Gateway)
   - Runs SQLite database and user rate limits
   - Processes standard free user renders locally in India with zero lag.

2. Pro VIP & Overflow Burst -> Modal Serverless:
   - Paid Pro subscribers get routed to Modal for instant, unthrottled 1080p renders.
   - When the Contabo local queue exceeds 2 active jobs, excess traffic overflows
     automatically to Modal instead of making users wait.
   - Monthly cost remains ~₹1,500 total while supporting enterprise-grade scaling.

6. ZERO-DOWNTIME MIGRATION STEPS (WHEN READY)
--------------------------------------------------------------------------------
Because the Flutter mobile app communicates strictly with:
    https://api.snapbeat.app

No mobile app update or App Store re-submission is needed to migrate servers:
1. Spin up the new Ubuntu 22.04 VPS (e.g. on Contabo Mumbai).
2. Install dependencies:
   sudo apt update && sudo apt install -y python3-pip python3-venv ffmpeg git
3. Clone repository and install requirements.txt.
4. Copy systemd service files (snapbeat-gateway, snapbeat-cult, snapbeat-classic).
5. Update DNS A-Record for "api.snapbeat.app" to the new VPS public IP.
6. Mobile apps automatically switch over to the new provider with zero downtime!
